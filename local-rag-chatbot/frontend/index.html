Because home internet routers use NAT firewalls, traffic to your public IP must be forwarded to this host PC:

Port to Forward 8000 (TCP)
  1. Log in to your Wi-Fi router admin page (usually http://192.168.1.1 or http://192.168.0.1).
  2. Navigate to Port Forwarding / Virtual Server settings.
  3. Add rule: External Port 8000 → Internal IP 192.168.1.8 → Internal Port 8000 (Protocol: TCP).
  4. Save and anyone on the internet can visit your public link!
